# 🍕 Pizza Play

Landing page de uma pizzaria fictícia, desenvolvida para praticar e demonstrar conhecimentos em desenvolvimento web.

##Tecnologias utilizadas
- HTML5
- CSS3
##Sobre o projeto
O projeto consiste em uma landing page moderna e responsiva para uma pizzaria, contendo:
- Página inicial
- Seção de promoções
- Cardápio
- Combos
- Pizzas mais pedidas
- Informações sobre a empresa
- Botão de contato pelo WhatsApp
- Layout responsivo

##  Objetivo
Praticar desenvolvimento front-end, estruturação de páginas, estilização com CSS.
